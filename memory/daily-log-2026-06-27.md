## Completed

### Email Preview Modal + Template Library — 5 commits, all reviewed clean

Full brainstorm → spec → plan → SDD execution cycle. Both features are live on the `develop` branch.

**Feature 1: Full-Screen Email Preview Modal**
- Replaced the old inline "Show preview / Hide preview" text toggle with a proper full-screen modal
- Desktop (600px) and Mobile (375px) toggle inside the modal with smooth width transition
- ESC key closes, clicking the dark overlay closes, "Keep editing" button closes
- "Looks good — Send Now" footer button sends the campaign directly from the modal
- `buildPreviewHtml()` was refactored into a pure `buildEmailPreviewHtml(params)` function so it can be reused by template thumbnails
- Security: iframe sandbox hardened to `sandbox=""` (maximum restriction, no scripts, no same-origin access)
- Security: HTML escape helper (`esc()`) added — all user-typed content (subject, body, CTA, discount code, etc.) is escaped before being rendered into the preview iframe

**Feature 2: Template Library Tab (3rd tab on Marketing page)**
- 4 pre-built branded email templates: Monthly Bench Notes, New Arrivals Spotlight, Seasonal Sale, Restock Alert
- Each card shows a live miniature thumbnail of the actual email layout (scaled-down iframe)
- "Use Template" button pre-fills the entire compose form and switches directly to the Campaigns tab with compose open
- All 4 templates are hardcoded constants — no database or API needed
