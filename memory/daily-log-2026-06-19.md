## Session 1 — CSV Bulk Import Feature (Built + Tested Live)

### What Was Built

A real CSV bulk import for the admin Products page. Previously the "Import CSV" button was a fake stub that did nothing. Now it works end-to-end.

**New file:** `app/api/admin/products/import/route.ts`
- Auth-guarded POST endpoint
- Accepts `{ rows: ImportRow[] }` (up to 500 rows per call — guard returns 400 if exceeded)
- Processes each row sequentially — duplicate check via `getProductByTitle`, collection GID resolution, then `createAdminProduct`
- 300 ms sleep between every Shopify API call (3 calls per new product: getProductByTitle → collectionHandlesToGids → createAdminProduct)
- Returns `ImportResult[]` with status `created | duplicate | error` per row
- Blank title guard returns `error` immediately without hitting Shopify

**Modified file:** `app/admin/products/page.tsx`
- CSV parser rewritten — switched from broken `.match()` regex (inserted spurious empty strings at every comma, shifting all column values by +1 and showing Short Description in Status column) to `split(/,(?=(?:[^"]*"[^"]*")*[^"]*$)/)` which correctly handles quoted fields
- CRLF line ending fix: `split(/\r?\n/)` so Windows/Excel-exported CSVs parse correctly
- `handleImportConfirm` now loops row-by-row client-side (1 row per API call), updating real progress live
- In-progress UI: real moving percentage bar ("12 of 34 · 35%") + live results list (✓ Created / ~ Duplicate / ✗ Error) that grows as each product finishes
- Done state: summary badges (created / duplicates / errors) + full per-row results table
- Double-submit guard: Import button disabled while `importing === true`
- Close modal blocked while importing

### Supporting Files Created

- `items-to-add.csv` — 34 draft products from Scott's inventory list, no prices/stock, "Scott No." column silently ignored by importer
- `scott-full-inventory.csv` — all 52 items with active/draft status
- `docs/superpowers/plans/2026-06-18-csv-bulk-import.md` — full implementation plan

### Column Mapping (CSV → Shopify)

CSV columns used by importer: Title, Short Description, SKU, Price, Compare-at Price, Stock, Status, Collections (semicolon-separated), Tags (semicolon-separated), Vendor, Material, Colour, Style, Brand, Vintage, Burner Size, Fits, Power Source, Era, Product Type, Condition, Edition, Workshop, Bench Tester, Bench Test Date, Net Weight.

"Scott No." column is silently ignored. Missing Price/Stock columns default to 0.

### Live Test Result

Imported `items-to-add.csv` on the live site — **34 of 34 created, 0 errors, 0 duplicates**. All 34 are now in Shopify as drafts at $0.00.
