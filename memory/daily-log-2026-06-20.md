# Daily Log — June 20, 2026

## Session 1 — CMS Cache Fix

Added `export const dynamic = 'force-dynamic'` to 6 storefront pages that read from Redis but were being statically cached by Next.js:
- `app/page.tsx`, `app/our-story/page.tsx`, `app/heritage/page.tsx`, `app/faq/page.tsx`, `app/shipping/page.tsx`, `app/returns/page.tsx`

Root cause: pages fetched Redis content via `getContent()` but had no dynamic directive, so Next.js cached the first render at build time. CMS saves were live in Redis but never shown on the storefront.

Also fixed two Tailwind canonical class warnings on returns and shipping pages.

**Commit:** `fix: force dynamic rendering on all CMS-driven pages to prevent stale Redis cache`
