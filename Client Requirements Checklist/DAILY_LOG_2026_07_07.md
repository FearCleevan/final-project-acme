## Part 1 — Acme Vintage Supply (Lamp Site)

### 1. Fixed the Favicon Showing the Wrong Icon in Google
Google search results were still showing a generic gray circle icon instead of the real Acme logo. We found the site's code had leftover duplicate icon settings fighting with each other, plus a proper "Apple touch icon" (used on iPhones) was missing. Cleaned this up so the correct logo is now served everywhere consistently. Also requested Google to re-scan the homepage sooner — but Google's own search-result icon can still take 1-2 weeks to visually update, even with a clean fix in place.

### 2. Fixed a Bug Hiding the Newest Product from the Admin Panel
Discovered that the admin Products page was silently capping itself at showing only the first 50 products. With 51 products now in the store, the newest one was invisible in the admin list (even though it still showed correctly on the storefront and in Inventory). Fixed the underlying code so the admin page now shows every product, no matter how many are added in the future.

### 3. Facebook & Social Media Marketing Support
Walked through how to actually market the store on Facebook, since many Facebook Groups don't allow business Pages or direct links to join/post. Put together a simple, practical playbook for posting in the 27 Facebook groups already gathered — split into two styles (collector groups vs. garage-sale groups), with example posts and a do's-and-don'ts checklist. Also helped set up Meta Business Suite (the free scheduling tool) and walked through creating the very first Facebook post.

### 4. Improved the "Link Preview" Image for Social Shares
When the store's website link is shared on Facebook/Messenger, it was showing a plain text-only preview card that looked like a business card. Rebuilt this preview image to show real product photos instead (oil lamps, glass shades, burners, signs), so shared links now look like an actual online store.

Also found the WordPress admin login is currently blocked (locked out by a security plugin due to repeated login attempts, likely from the ongoing attack). Helped draft two emails to Scott explaining the access issue and asking him to follow up with the original developer (Evan Mugford).

### 2. Found an Existing, More Advanced Version of the New Site
While looking for what's already been built for the new acmesign.ca, found a project folder that was much further along than expected — a real working version of the new site already using **all 271 of the real job photos** Scott's business has, with a modern design, but built before some of Scott's more recent feedback (like making LED Signs a priority feature).

### 3. Made the New Site Actually Show Off Scott's Real Work
The biggest gap found: the new site had only one photo per service category, while dozens (in some cases 90+) real job photos were sitting unused. Fixed this by:
- Building a proper **photo gallery on every single service page**, pulling from Scott's real job photos
- Building a full **"Project Gallery" page** showing all 236 real photos, with filter buttons by service type and a click-to-zoom viewer
- Fixing 3 service listings that were accidentally showing the exact same photo
- Building dedicated, richer pages for **LED Signs** and **Vehicle Wraps** (previously generic/thin pages)
- Building a proper standalone **Contact page** with a map

### 4. Made the Site Fast and Search-Engine Ready
Since the site is now much more image-heavy, did a full check to make sure photos load quickly and don't slow the site down. Also added the technical groundwork so Google (and AI tools like ChatGPT) can correctly find and describe the business — including the full list of areas Scott's business serves (Halifax, Dartmouth, Bedford, and more).

### 5. Found and Fixed Two Visual Bugs
- The logo in the site's footer was rendering as an unreadable white blob instead of the real black-and-red "ACME SIGN" logo
- The large decorative "ACME SIGN" watermark text in the footer background was getting cut off at the top

Both are now fixed and confirmed working.

### 6. Checked Mobile — Confirmed It Works
Went through the new pages on a phone-sized screen to confirm nothing breaks — menus, photo galleries, and forms all resize correctly with no overlapping or cut-off content.

### 7. Got the New Site Online for the First Time
